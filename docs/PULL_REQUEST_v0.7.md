# v0.7: перерывы между заданиями, навыки без паузы и выделение своего шара

Непрерывные задания и полноэкранный магазин мешали смотреть бой. После успешного задания добавлен перерыв 3 секунды, награды увеличены. Перед матчем можно выбрать два варианта развития: навык за заполнение шкалы 60 эссенции или покупка каждые 30 секунд.

Три карточки появляются в нижней панели вместо мини-игры на 7 секунд. Бой продолжается, нажатие сразу применяет один навык и возвращает задание. При бездействии применяется первый доступный; цель помехи указана заранее. Боты тоже получают один навык из трёх, без общей паузы. Старые магазин и окно списка покупок удалены.

Свой шар и выбранный участник ставки выделены синей обводкой с тёмным разделителем. Внутри всех шаров только крупное HP; номера остались в карточках участников.

Сохраняются предложения, остатки времени и точный доход ботов. Матчи v0.6 переносятся с сохранением боя, эссенции и усилений; правила ставок не меняются, возврат не требуется. Unity-проект, README и описание режима обновлены. Android APK 0.7.0 / versionCode 8 публикуется в android-builds.

Проверки: полный набор 140 EditMode-тестов и финальные 34 сценария v0.7, включая три дополнительных случая повреждённых сохранений.

Фактические результаты проверок: [VALIDATION.md](VALIDATION.md).
