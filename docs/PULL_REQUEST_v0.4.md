# v0.4: физика по референсам, очередь лука, арбалет и отражающий щит

Переработано движение по пяти видео: упругие отскоки без обязательной высоты прыжка и горизонтального разгона, гравитация 16,7 и сохранение импульса при столкновении тел. Оружие получило разные скорости вращения, контактную реакцию вместо общего разворота и корректную интерполяцию быстрых оборотов. Клинок стал коротким и быстрее разгоняется; удерживаемое дальнее оружие участвует в контактах без урона рукоятью.

Лук выпускает последовательную очередь из одного места с удержанием направления; прежний веер перенесён на новый арбалет. Щит не атакует касанием, возвращает 100% прямого урона и увеличивает ширину после нанесённого возвращённого урона. Снаряды отражаются со сменой владельца; промах не усиливает щит. Безоружный получил растущий предел скорости, урон от скорости перед ударом и визуальный след.

Обновлены сохранённые сцена и ресурсы Unity, документация и Android APK 0.4.0. Проверки: 63 EditMode-теста; на подключённом телефоне — бои меч/копьё, лук/щит, арбалет/щит и безоружный/клинок без перезапусков между боями. Баланс предварительный; щит–щит без снарядов не имеет источника урона.
