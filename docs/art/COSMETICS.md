# Персонажи v0.10

Пять оригинальных персонажей созданы встроенным инструментом **image_gen**, по одному вызову на образ. CLI и сторонние наборы изображений не использовались. Полный набор запросов сохранён в [v0.10-prompts.json](v0.10-prompts.json).

Исходные PNG с настоящей прозрачностью находятся в `Assets/ArmOrb/Resources/Cosmetics/`: `robot.png`, `cat.png`, `ninja.png`, `astronaut.png`, `knight.png`. Исходный размер 1254×1254. Unity импортирует их как одиночные спрайты максимум 128×128, без mipmaps, с фильтром Point и без сжатия. Исходные изображения не перезаписываются импортёром.

Палитра нейтральная: в игре спрайт окрашивается цветом участника поверх основного круглого тела. Детали лица находятся выше области HP. Косметика не передаётся в численную симуляцию и не изменяет столкновения. У рыцаря есть небольшой гребень, который остаётся внутри полного квадратного спрайта; физическое тело по-прежнему круг.

Следы рисуются кодом без внешних текстур. Для всех шаров действует общий бюджет до 32 видимых элементов следа за кадр.
